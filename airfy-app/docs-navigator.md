## 🚀 Быстрый старт

### Установка и запуск

```bash
# Клонируйте репозиторий
git clone https://github.com/Kacheer/Airfy.git
cd Airfy/airfy-app

# Установите зависимости
npm install

# Запустите приложение в режиме разработки
npm run dev

# Приложение будет доступно по адресу http://localhost:5173
```

## 📝 Соглашения кода

### Логирование

Все логи должны использовать префиксы:
- `[APP]` — события приложения
- `[API]` — запросы и ответы API
- `[STORE]` — операции с хранилищем
- `[DS]` — операции DataService

Пример:
```javascript
console.log("[API] Получаем прогноз для координат:", lat, long)
```

### Структура компонентов

<script>
export default {

## ❓ Часто задаваемые вопросы

**В: Как открыть консоль браузера?**
А: Нажмите `F12` или `Ctrl+Shift+I` на Windows/Linux, `Cmd+Option+I` на Mac.

**В: Где хранятся данные о погоде?**
А: В `localStorage` под ключом `serverStore`. Смотрите [Система кеширования](./03-caching-system.md).

**В: Как обновить данные принудительно?**
А: Вызовите `apiForecast.fetchForecast(true)` с параметром `force=true`.

**В: Какие WMO коды погоды поддерживаются?**
А: Смотрите таблицу в [API интеграция](./04-api-integration.md#wmo-коды-погоды).

**В: Как добавить новый язык?**
А: Откройте `src/lang/language.js` и добавьте переводы.
