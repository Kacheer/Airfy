# Airfy — Приложение для прогноза погоды

**Airfy** — это современное веб-приложение для получения актуальной информации о погоде, построенное на основе Vue.js 3 и Vite. Приложение использует API Open-Meteo для получения метеорологических данных с кэшированием на клиенте для оптимизации производительности.

## Быстрый старт

### Требования

- Node.js (версия 18 и выше)
- npm или yarn

### Установка и запуск

1. **Клонируйте репозиторий:**
   ```bash
   git clone https://github.com/Kacheer/Airfy.git
   cd Airfy/airfy-app
   ```

2. **Установите зависимости:**
   ```bash
   npm install
   ```

3. **Запустите приложение в режиме разработки:**
   ```bash
   npm run dev
   ```
   Приложение будет доступно по адресу `http://localhost:5173`

4. **Создайте production сборку:**
   ```bash
   npm run build
   ```

5. **Просмотрите production сборку локально:**
   ```bash
   npm run preview
   ```

## Инструменты и технологии

### Основные фреймворки и библиотеки

- **Vue.js 3** — реактивный фреймворк для построения интерфейса
- **Vite** — быстрый сборщик приложений с горячей переработкой модулей (HMR)
- **Pinia** — система управления состоянием приложения (state management)
- **Axios** — HTTP клиент для работы с API
- **GSAP** — библиотека для анимаций
- **Three.js** — 3D графика для динамического фона
- **pinia-plugin-persistedstate** — плагин для сохранения состояния в localStorage

## Тестирование

### Методы тестирования в браузере

1. **Консоль браузера (для просмотра логов):**
   - **Chrome/Edge**: Нажмите `F12` или `Ctrl+Shift+I` (Windows/Linux) / `Cmd+Option+I` (Mac)
   - **Firefox**: Нажмите `F12` или `Ctrl+Shift+K` (Windows/Linux) / `Cmd+Option+K` (Mac)
   - **Safari**: Включите "Develop" в меню, затем `Cmd+Option+I`

2. **Вкладка Console:**
   - Все логи приложения выводятся с префиксами: `[APP]`, `[API]`, `[STORE]`, `[DS]`
   - Позволяет отслеживать процесс загрузки данных
   - Показывает ошибки и предупреждения

3. **DevTools для отладки:**
   - **Application/Storage**: Просмотрите localStorage и найдите сохраненные данные о погоде
   - **Network**: Контролируйте запросы к API Open-Meteo
   - **Vue DevTools**: Установите расширение [Vue DevTools](https://devtools.vuejs.org/) для инспекции компонентов и состояния Pinia

### Ручное тестирование функций

- Откройте приложение в браузере
- Нажмите `F12` для открытия Developer Tools
- Откройте вкладку **Console**
- Позвольте приложению запросить доступ к вашему местоположению
- Наблюдайте логи загрузки данных:
  - `[API] Обновляем данные с сервера`
  - `[DS] Модель ежедневных данных собрана`
  - `[STORE] Данные daily обновлены`
