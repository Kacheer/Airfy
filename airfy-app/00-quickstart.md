# 🚀 Быстрое руководство по структуре Airfy

Это краткое руководство поможет вам быстро ориентироваться в коде Airfy.

## 📁 Где что находится

### 🎨 UI Компоненты (`src/components/`)

```
CurrentForecast.vue          → Большой дисплей текущей температуры
├─ Показывает температуру
├─ Иконку погоды
└─ Описание

CurrentForecastDetails.vue   → Детали текущей погоды в карточках
├─ Влажность
├─ Давление
├─ Видимость
├─ Скорость ветра
└─ и другие параметры

DailyCard.vue                → Карточка одного дня
├─ День недели/дата
├─ Иконка погоды
└─ Температура и вероятность осадков

HourlyCard.vue               → Карточка одного часа
├─ Время
├─ Температура
└─ Иконка и вероятность осадков

Header.vue                   → Заголовок приложения
├─ Выбор города
├─ Выбор языка
└─ Кнопка обновления

Footer.vue                   → Подвал
LoadingScreen.vue            → Экран загрузки
SimpleDynamicBackground.vue  → 3D фон (Three.js)
```

### 🔌 API Модули (`src/api/`)

```
apiForecast.js       → Запросы к Open-Meteo API для прогноза
├─ fetchForecast()   → Основной метод для получения данных
└─ Кэширование (10 минут)

apiLocation.js       → Преобразование координат в названия городов
apiBrowser.js        → Геолокация браузера
└─ getPos()          → Получить координаты пользователя
```

### 💾 Управление состоянием (`src/store/`)

```
index.js             → Инициализация Pinia с плагинами
userStore.js         → Координаты и данные пользователя
└─ userPos, city, language

Serverstore.js       → Метеорологические данные
├─ current           → Текущая температура
├─ daily[7]          → Прогноз на 7 дней
├─ hourly (в daily)  → Почасовой прогноз для каждого дня
└─ lastFetched       → Время последней загрузки для кэша
```

### 🛠️ Сервисы (`src/services/`)

```
DataService.js       → Трансформация данных API в модели
├─ addPosToStore()   → Сохраняет координаты
├─ addResponseToStore() → Преобразует API ответ
└─ getAllData()       → Получает все данные

Convert.js           → Конвертация единиц измерения
offcetGeo.js         → Утилиты геолокации
```

### 🗂️ Другое

```
src/lang/language.js       → Многоязычная поддержка
src/styles/style.css       → Глобальные стили
src/assets/weather-icons/  → Иконки погодных условий
public/SvgIcon.vue         → SVG иконки
```

## 🔄 Жизненный цикл приложения

### 1️⃣ Запуск приложения

```
Browser loads → App.vue mounted()
  ↓
apiBrowser.getPos() → Получает координаты GPS
  ↓
DataService.addPosToStore() → Сохраняет в userStore
  ↓
apiForecast.fetchForecast() → Запрашивает прогноз
  ↓
Open-Meteo API ← Возвращает данные
  ↓
DataService.addResponseToStore() → Трансформирует данные
  ↓
Serverstore ← Сохраняет в Pinia
  ↓
localStorage ← Автосохранение (persistedstate)
  ↓
Vue компоненты ← Обновляют UI (reactively)
```

### 2️⃣ Обновление приложения

```
Пользователь нажал на день
  ↓
HourlyCard компонент получил почасовые данные
  ↓
Компонент отображает прогноз на этот день
```

### 3️⃣ Переиспользование кэша

```
Пользователь перезагрузил страницу < 10 минут спустя
  ↓
localStorage автоматически восстанавливает данные
  ↓
UI обновляется мгновенно
  ↓
API запрос НЕ делается (экономим трафик!)
```

## 🔧 Как добавить новую функцию

### Пример: Добавить alert при опасной погоде

1. **Отредактируйте Serverstore.js** (`src/store/Serverstore.js`)
   - Добавьте новое поле: `alertActive: false`

2. **Добавьте метод** в `Serverstore.js`
   ```javascript
   checkForAlerts() {
     this.daily.forEach(day => {
       if (day.weather_code >= 95) {  // Гроза
         this.alertActive = true
       }
     })
   }
   ```

3. **Вызовите метод** из `DataService.js`
   ```javascript
   serverStore.checkForAlerts()
   ```

4. **Создайте новый компонент** `Alert.vue` в `src/components/`
   ```vue
   <template>
     <div v-if="serverStore.alertActive" class="alert">
       ⚠️ Внимание: ожидается гроза!
     </div>
   </template>
   ```

5. **Добавьте компонент** в `App.vue`

Откройте консоль (`F12` → **Console**) и смотрите логи:

```

[API] Позиция пользователя получена: 55.7558, 37.6173
[API] Обновляем данные с сервера
[API] Данные успешно получены: {...}
[DS] Модель ежедневных данных собрана!
[STORE] Данные daily обновлены: Array(7)
[DS] Ежедневные данные отправлены в хранилище!
[DS] Модель почасовых данных отправлена в хранилище!
```

### Префиксы логов

| Префикс | Значение |
|---------|----------|
| `[APP]` | События приложения (инициализация, загрузка тем) |
| `[API]` | API запросы и ответы |
| `[STORE]` | Операции с Pinia хранилищем |
| `[DS]` | DataService операции |

## 🧪 Быстрые команды для тестирования

### В консоли браузера (F12)

```javascript
// Получить текущую температуру
const store = window.__PINIA__.useServerStore()
console.log("Температура:", store.current.temperature)

// Получить весь прогноз
console.log("Прогноз на 7 дней:", store.daily)

// Проверить, когда были загружены данные
const mins = (Date.now() - store.lastFetched) / (60 * 1000)
console.log("Минут с последней загрузки:", mins.toFixed(1))

// Очистить кэш
localStorage.clear()
location.reload()
```

## 🐛 Отладка проблем

### Проблема: Ничего не загружается

```javascript
// В консоли браузера
const store = window.__PINIA__.useServerStore()
console.log("Данные:", store.$state)
// Если empty, значит API запрос не сработал
```

### Проблема: Кэш старый

```javascript
// В консоли браузера
localStorage.clear()
location.reload()
```

### Проблема: Геолокация не работает

```javascript
// В консоли браузера
const userStore = window.__PINIA__.useUserStore()
console.log("Координаты:", userStore.userPos)
// Если null, значит браузер не получил разрешение
```
