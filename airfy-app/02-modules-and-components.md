# Модули и компоненты Airfy

## Структура модулей

### API слой (`src/api/`)

#### apiForecast.js

**Назначение**: Получение прогноза погоды от сервера Open-Meteo.

**Основной метод**: `fetchForecast(force = false)`

```javascript
async fetchForecast(force = false) {
  // 1. Ждет получения координат пользователя
  // 2. Проверяет кэш (если данные < 10 минут и force=false, используются из localStorage)
  // 3. Если нужно обновление, делает запрос к API Open-Meteo
  // 4. Передает данные в DataService для трансформации
  // 5. Сохраняет время последней загрузки
}
```

**Параметры запроса:**
- `latitude`, `longitude` — координаты пользователя
- `daily` — ежедневные параметры (восход, закат, код погоды, температура, влажность и т.д.)
- `hourly` — почасовые параметры (температура, осадки, видимость и т.д.)
- `current` — текущие параметры (температура, код погоды)
- `timezone` — часовой пояс (автоматический)
- `timeformat` — формат времени (Unix timestamp)

**Endpoint**: `https://api.open-meteo.com/v1/forecast`

**Кэширование**: 10 минут (600000 мс). Если запрос в пределах 10 минут, данные загружаются из localStorage.

#### apiBrowser.js

**Назначение**: Работа с браузерным API геолокации.

**Основной метод**: `getPos()`

```javascript
getPos() {
  // 1. Запрашивает текущее местоположение через navigator.geolocation
  // 2. Применяет случайное смещение (±5 км) для приватности
  // 3. Возвращает координаты в формате { lat, long }
}
```

**Процесс:**
1. `navigator.geolocation.getCurrentPosition()` — получает координаты с точностью GPS
2. `offcetGeo._generateRandomOffset()` — добавляет случайное смещение
3. Возвращает объект: `{ lat: 55.7558, long: 37.6173 }`

**Обработка ошибок**: Если пользователь не дает разрешение на геолокацию, выводится ошибка в консоль.

### Слой бизнес-логики (`src/services/`)

#### DataService.js

**Назначение**: Центральный сервис для трансформации, валидации и управления данными о погоде.

**Методы:**

##### `addPosToStore(lat, long)`
Сохраняет координаты пользователя в `userStore`.
```javascript
addPosToStore(55.7558, 37.6173)
// → Сохраняет в userStore.userPos
```

##### `addResponseToStore(response)`
Трансформирует сырые данные от API в модели для хранилища.

**Процесс трансформации:**

1. **Текущая погода** (`setCurrent`)
   - Температура и код погоды сохраняются в `current`

2. **Ежедневные данные** (`setDailyForecast`)
   ```javascript
   // Для каждого дня (7 дней):
   {
     time: timestamp_восхода,
     temperature: средняя_температура,
     feelsLike: ощущаемая_температура (усредненная из 24ч),
     weather_code: код_погоды,
     precipitation_probability: вероятность_осадков,
     pressure_max/min: максимум/минимум_давления,
     humidity: влажность,
     visibility: видимость,
     wind_speed: скорость_ветра,
     sunrise/sunset: время_восхода/заката,
     hourly: [] // будет заполнено далее
   }
   ```

3. **Почасовые данные** (`addHourlyForecast`)
   ```javascript
   // Для каждого часа (24 часа × 7 дней = 168 записей):
   {
     time: timestamp,
     weather_code: код_погоды,
     temperature: температура,
     apparent_temperature: ощущаемая_температура,
     humidity: влажность,
     precipitation_probability: вероятность_осадков,
     precipitation: количество_осадков,
     visibility: видимость
   }
   ```

**Логирование**: Все шаги логируются с префиксом `[DS]`

##### `printForecastData()`
Выводит данные из `localStorage` в консоль для отладки.

##### `getPosStore()`
Возвращает сохраненные координаты пользователя.

##### `getAllData()`
Возвращает все метеорологические данные из хранилища:
```javascript
{
  units: { temperature, pressure, wind_speed },
  current: { temperature, weather_code },
  daily: Array(7)
}
```

##### `waitForCoordinates()`
Ждет получения координат пользователя (опрашивает каждые 100 мс).

#### Convert.js

**Назначение**: Конвертация единиц измерения и форматирование данных.

*Примечание: Этот модуль может быть расширен для поддержки конвертации Цельсия в Фаренгейт, м/с в км/ч и т.д.*

**Ожидаемые методы:**
- `celsiusToFahrenheit(temp)` — конвертация температуры
- `msToKmh(speed)` — конвертация скорости ветра
- `formatDate(timestamp)` — форматирование даты
- `formatWeatherCode(code)` — преобразование кода погоды в описание

---

#### offcetGeo.js

**Назначение**: Утилиты для работы с геолокацией.

**Метод**: `_generateRandomOffset(lat, long, radiusKm)`

Генерирует случайное смещение координат для приватности пользователя.

```javascript
_generateRandomOffset(55.7558, 37.6173, 5)
// → { lat: 55.7589, long: 37.6145 } (смещение в пределах 5 км)
```

**Реализация:**
- Генерирует случайный угол (0-360°)
- Генерирует случайное расстояние (0-radiusKm)
- Вычисляет новые координаты с использованием формул геодезии
- Возвращает новые координаты

### Слой управления состоянием (`src/store/`)

#### index.js

**Назначение**: Инициализация Pinia и подключение плагинов.

```javascript
import { createPinia } from 'pinia';
import piniaPluginPersistedstate from 'pinia-plugin-persistedstate';

const pinia = createPinia();
pinia.use(piniaPluginPersistedstate);
```

**Что происходит:**
1. Создается экземпляр Pinia
2. Подключается плагин `persistedstate` для автоматического кэширования в localStorage
3. Pinia экспортируется для использования в компонентах и сервисах

---

#### userStore.js

**Назначение**: Хранение данных о пользователе.

**Состояние (state):**
```javascript
{
  userPos: { lat, long },     // Координаты пользователя
  city: string,               // Выбранный город
  language: string,           // Выбранный язык ('Русский', 'English' и т.д.)
  requestTime: number         // Timestamp последнего запроса
}
```

**Действия (actions):**
- `setUserPos(lat, long)` — сохраняет координаты
- `getUserPos()` — получает координаты
- `setRequestTime()` — устанавливает текущее время запроса
- `getRequestTime()` — получает время последнего запроса

**Особенность**: `persist: true` — состояние автоматически сохраняется в localStorage и восстанавливается при перезагрузке.

---

#### Serverstore.js

**Назначение**: Хранение метеорологических данных с кэшированием.

**Состояние (state):**
```javascript
{
  units: {
    temperature: string,      // '°C', '°F'
    pressure: string,         // 'hPa'
    wind_speed: string        // 'm/s', 'km/h'
  },
  current: {
    temperature: number,      // Текущая температура
    weather_code: number      // Код текущей погоды (WMO код)
  },
  daily: Array(7) {           // Прогноз на 7 дней
    time,
    temperature,
    feelsLike,
    weather_code,
    precipitation_probability,
    pressure_max,
    pressure_min,
    humidity,
    visibility,
    wind_speed,
    sunrise,
    sunset,
    hourly: Array(24)         // 24 почасовых прогноза
  },
  lastFetched: number         // Timestamp последней загрузки
}
```

**Действия (actions):**
- `setCurrent(temperature, weather_code)` — сохраняет текущую погоду
- `setUnits(temperature, pressure, wind_speed)` — сохраняет единицы измерения
- `setDailyForecast(dailyData)` — устанавливает ежедневный прогноз на 7 дней
- `getDailyForecast()` — получает ежедневный прогноз
- `addHourlyForecast(daily_id, hourlyModel)` — добавляет почасовой прогноз к дню
- `getAll()` — получает все данные (units, current, daily)
- `loadState()` — загружает состояние из localStorage
- `saveState()` — сохраняет состояние в localStorage

**Особенность**: Поддерживает явное сохранение и загрузку из localStorage через `loadState()` и `saveState()`.

## Компонентная архитектура

```
App.vue (корневой компонент)
├── Header.vue
│   ├── Выбор города
│   ├── Выбор языка
│   └── Кнопка обновления
├── SimpleDynamicBackground.vue (3D фон)
├── LoadingScreen.vue (в процессе загрузки)
├── CurrentForecast.vue (текущая температура)
├── CurrentForecastDetails.vue (детали текущей погоды)
├── DailyCard.vue × 7 (карточки на 7 дней)
│   └── HourlyCard.vue × 24 (при нажатии на день)
└── Footer.vue
```

## Жизненный цикл компонентов

### App.vue

1. **created()** — инициализация состояния и подключение плагинов
2. **mounted()** — запрос геолокации и загрузка данных
3. **watch** — реактивные обновления при изменении состояния

### CurrentForecast.vue и другие UI компоненты

1. **props** — получение данных от родительского компонента
2. **computed** — вычисляемые свойства (форматирование, конвертация)
3. **render** — отображение данных в DOM
